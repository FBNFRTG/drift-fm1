# Contributing to DRIFT

Report reproducible bugs and feature requests at https://github.com/FBNFRTG/drift-fm1/issues . Include the DRIFT version, device or browser/OS, steps, expected result and actual result. Never include personal data or credentials.

Keep changes focused, preserve upstream copyright and licence notices, and run the relevant checks in BUILDING.md. Test updates and outgoing updates on a real FM-1 before publishing firmware. The project identity remains FM-1_983.
