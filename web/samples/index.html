FORMAT & STORAGE

Three slots, 80 KiB each. Up to 7.383 seconds per sample, mono, 22,050 Hz, stored as 4-bit IMA ADPCM. Stereo files are mixed down and resampled in your browser. WAV is recommended; other formats depend on browser support. Long files are rejected, never silently trimmed.

Root note: original pitch, 60 = C4. Other keys transpose the sample. Loop: repeats the full sample while its envelope is active. Prepare matching start/end points for seamless loops. On the FM-1, select GLO → WAVE → SAMPLE 1–3. MIX sets sample level.

USB upload requires DRIFT 0.3–0.8 and Web MIDI/SysEx in Chrome or Edge over HTTPS or localhost. Select the FM-1 input/output and check the device before uploading. Upload stops playback. Replace overwrites the selected slot. The memory layout has changed from DRIFT 0.2: back up and reload your samples.

All audio processing stays in your browser. No audio is uploaded to a server. An interrupted transfer leaves the target slot incomplete; upload again. USB transfer is software-tested but has not been tested here on physical hardware.
