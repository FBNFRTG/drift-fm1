What changed

Version 0.9.1 expands DIR and INTERVAL, offers 999 deterministic CHAOS variations and groups effects into Delay, Reverb and Misc. Delay times now extend to four bars without clipping to the short audio buffer. Patch/sample addresses remain unchanged; old CHAOS patterns and effect colour can sound different. Release builds keep FM-1_983 instead of generating a Felucca identity.

Test status

Firmware build and memory checks, native synthesis/UI tests, WebAssembly audio/persistence tests and simulated USB update/loader checks are supplied in the release bundle. These are software tests.

Physical FM-1 tests for this exact 0.9.1 package have not yet been recorded. Required before a Firmware Hub submission: install from V15 and another custom firmware, verify USB identity, switch from DRIFT to another firmware, and verify recovery/resume. Earlier DRIFT versions have been tried on the creator's FM-1; that does not establish these checks for this release. No Hub approval or listing is claimed.

Data compatibility

DRIFT 0.9.1 retains the 0.8 storage layout. Extended CHAOS is stored in spare record bytes. Nonzero CHAOS patterns and FX colour can change; the old delay Tone becomes Reverb Tone. The loader protects the user data areas, and older DRIFT patches receive defaults only for missing newer settings. Samples use three 80 KiB slots. A switch to other firmware is a separate operation: it may read or overwrite these areas differently. Keep backups; compatibility with third-party patches and projects is not promised.

Build the source

Unzip the source archive and follow BUILDING.md and README-DRIFT.md. A Linux x86-64 JieLi toolchain and the AC79 SDK are required. The source includes the engine files; no GitHub account is needed to download or build it.

JIELI_TOOLCHAIN=/path/to/toolchain AC79_SDK=/path/to/sdk sh build.sh
# Output: build/felucca.fwsc — product FM-1_983
# For browser code, activate Emscripten 4.0.18, then:
EMU_PREVIEW=0 sh web/emu/build.sh

Upstream SDK/toolchain downloads are listed in the build instructions. The produced package includes Felucca's update loader. Full changelog.
